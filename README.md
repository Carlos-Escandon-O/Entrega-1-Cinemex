# 🎬 Clon de Cinemex — Entrega 1 (Análisis y diseño UML)

**Proyecto final de la materia de Programación Orientada a Objetos (POO).**

Es el análisis y diseño orientado a objetos de un sistema de escritorio en Java con interfaz gráfica, inspirado en la página de **Cinemex** (cadena de cines). El sistema permite consultar la cartelera, ver la información de una película, elegir un cine, revisar horarios, seleccionar asientos y comprar boletos.

## 👥 Roles de usuario

| Rol | Qué puede hacer |
|---|---|
| **Visitante** | Solo consulta (cartelera, películas, cines, horarios) |
| **Cliente registrado** | Compra boletos y consulta su historial |
| **Administrador** | Da de alta películas y programa funciones |

| Archivo | Descripción |

## 📚 Contenido del documento (21 páginas)

- **1. Descripción del proyecto y objetivo** — análisis de la página de Cinemex y objetivos (general y específicos)
- **2. Análisis de la página de cinemex** — flujo completo de compra, sección por sección (cartelera, detalle, cine, horarios, asientos, pago, sesión, promociones), con tabla de "qué necesita el sistema" para cada una
- Cómo fluye el usuario: cartelera → buscar/película → elegir cine → horarios → seleccionar asientos → pago → confirmación
- Capturas de pantalla de cada sección pública de la página
- **Diagramas UML:**
  - **Casos de uso** (visitante, cliente registrado, administrador)
  - **Actividades** (flujo del proceso de compra)
  - **Clases** (el modelo orientado a objetos)
  - **Secuencia** (la interacción actor ↔ pantallas)
- Garantía de que los diagramas son coherentes entre sí y cada clase tiene una responsabilidad clara (nada de lógica concentrada en una sola clase)

## 🎯 Objetivo del proyecto

Analizar el funcionamiento de Cinemex y diseñar, mediante UML, la solución orientada a objetos que servirá como base para la implementación en Java (Entrega siguiente). Es la primera de las entregas del proyecto final.
